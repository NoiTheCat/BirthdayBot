# Birthday Bot

**The original Discord birthday bot!**

Birthday Bot is a utility that allows the members of your community to share their birthdays and check the birthdays of others. It is versatile, customizable, and is under active development with new features being suggested and added often. This bot can mark and announce birthdays as they happen, allowing users and moderators to set time zones to ensure all birthdays can be recognized right on time.

### Getting started
Use [this link](https://discord.com/oauth2/authorize?client_id=470673087671566366&permissions=268451840&scope=applications.commands+bot) to invite the bot to a server of your choosing. During the setup process, the following permissions are requested:
* **Manage Roles**: Allows for adding and removing users from a configured *birthday role*, if enabled.
* **Embed Links**: Required for showing certain messages properly.

Next, you might like to do the following:
* Set up a role (purely cosmetic) for the bot to assign to members during their birthday and set it with `/config role set-birthday-role`
* Set up birthday announcements by designating an announcement channel with `/config announce set-channel`
  * See `/config announce help` for more options

Have a look at the `/help` and `/config announce help` commands for further options available to users and/or moderators.
